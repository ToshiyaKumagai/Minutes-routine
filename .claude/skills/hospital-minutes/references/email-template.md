# 送付メールの型

議事録を作ったら、それを送るメール文面まで用意する。`message_compose_v1` で提示すると、そのままメールアプリに渡せる。

## 構成

```
件名：【○○病院様】M/D ＜会議名＞議事録の送付と、＜主な依頼＞のご依頼

＜宛名＞様

いつもお世話になっております。株式会社ヘンリーの＜担当者＞です。
本日はお忙しいところ、＜会議名＞のお時間をいただき、誠にありがとうございました。

本日の議事録と、＜同送資料＞をお送りいたします。
院内でのご共有にご活用いただけますと幸いです。

＜AI作成の注記（1段落）＞

■ 添付資料
・＜ファイル名＞
・＜ファイル名＞

■ 参考リンク
＜URL＞

──────────────────

■ ご依頼事項

1. ＜依頼の見出し＞
＜具体的な内容。何を、どう、いつまでに＞

2. ＜依頼の見出し＞
...

──────────────────

ご不明な点がございましたら、お気軽にご連絡ください。

引き続きどうぞよろしくお願いいたします。
```

## 書き方の要点

**依頼は番号付きで、1件1目的。** 「〜と〜をお願いします」と1項目に詰め込まない。受け取った側がチェックリストとして使える形にする。

**各依頼に、何をすればよいかを1〜3行で添える。** 見出しだけだと解釈が分かれる。期限がある依頼には期限と、その期限の理由（例：9月開始の部会に間に合わせるため）を書く。理由があると優先順位がつけられる。

**病院側の負担を下げる情報を書く。** 「分類は弊社で整理してご提案しますので、貴院側で整えていただく必要はございません」のように、やらなくてよいことを明示すると着手されやすい。

**AI作成の注記を添付資料一覧より前に置く。** 添付を開く前に前提が伝わるようにする。

**メールアドレスは本文に書かない。** 宛先本人のアドレスであっても「本メールの宛先アドレス宛に」と表現する。顧客の個人情報を成果物に残さないため。宛先欄への入力は利用者が行う。

**ログインURL・動画URL等は本文に直接書く。** リンク切れを避けるため短縮しない。

**依頼が1件もない回もある。** その場合は「ご依頼事項」ブロックごと落とし、議事録の送付と確認のお願いだけにする。無理に依頼を作らない。

## 件名の例

- 【吉見病院様】8/12 部門別キックオフ（病棟看護）議事録の送付と、数値評価レビュー等のご依頼
- 【○○病院様】9/3 第1回運用検討部会 議事録のご送付
- 【○○病院様】10/15 リハーサル①振り返り 議事録と、次回までのご確認事項
