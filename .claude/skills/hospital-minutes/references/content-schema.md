# content.json スキーマ

`scripts/build_minutes.js` に渡す JSON の形式。

## 全体構造

```json
{
  "eyebrow": "○○病院様　電子カルテ導入プロジェクト",
  "title": "部門別キックオフ（病棟看護）議事録",
  "subtitle": "2026年8月12日（水）実施　／　作成：株式会社ヘンリー",
  "meta": [
    ["会議名", "..."],
    ["実施日", "2026年8月12日（水）"],
    ["出席者", "..."],
    ["目的", "..."]
  ],
  "ai_notice": true,
  "sections": [ ... ],
  "footer": "..."
}
```

| フィールド | 必須 | 内容 |
|---|---|---|
| `eyebrow` | 任意 | タイトル上の小さい行。病院名＋プロジェクト名 |
| `title` | **必須** | 文書タイトル |
| `subtitle` | 任意 | タイトル下の細い行。実施日・作成者 |
| `meta` | 任意 | 会議情報テーブル。`[見出し, 内容]` の配列 |
| `ai_notice` | 任意 | `true`（既定文言）／文字列（差し替え）／`false`（非表示）。**原則 true** |
| `sections` | **必須** | 本文セクションの配列 |
| `footer` | 任意 | 末尾の注記。省略時は既定文言 |

## sections

```json
{
  "h1": "1. 全体スケジュール",
  "body": [
    { "h2": "1-1. 稼働までの流れ" },
    { "bullet": "稼働開始日は2026年12月1日。" },
    { "bullet": "① 運用構築・設計（〜8月）", "level": 1 },
    { "para": "通常の段落テキスト。" },
    { "note": "※ 補足。小さいグレー文字で表示されます。" },
    { "link": { "label": "説明動画（YouTube）", "url": "https://..." } }
  ]
}
```

ブロック種別は 5 つだけ。

- `h2` — 小見出し（緑）
- `bullet` — 箇条書き。`level: 1` で 1 段下げ（`－` 記号）
- `para` — 通常段落
- `note` — 小さいグレー文字の補足
- `link` — 「ラベル：URL」形式のハイパーリンク

## 書式について

色・フォント・余白・改ページ制御はスクリプト側で固定されています。JSON で指定する必要はありませんし、指定もできません。書式を変えたいときはスクリプトを直接編集してください。

見出しには `keepNext` が入っているため、見出しだけがページ末尾に取り残されることはありません。
